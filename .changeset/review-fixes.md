Fix bugs found in review. `memoryAdapter` no longer rejects a write that succeeded when a subscriber throws. `withRetry` returns an `unavailable` result naming the key when its `sleep` rejects, and starts no attempt after an abort during the wait. `withFallback` checks `ifRevision` on the secondary when the primary could not take the write, so a stale revision is a `conflict` instead of an overwrite. `withReadCache` no longer stores a read that a later write, removal or change notice overtook, so a removed value is not brought back. `withEncoding` reports a value that cannot be decoded to the new optional `onSubscribeError(key, message)` instead of dropping it, and delivers changes in order. `createPersistence` throws for the envelope's own field names `v` and `savedAt` (they made saved values unreadable); a merge function runs once and a second conflict returns `outcome: 'conflict'` instead of merging again and again; a queued forced save no longer makes the save that replaced it forced; and a failed `remove` no longer forgets the tracked revision or a failed save the text it echo-filters. Uncached `documentFileAdapter` reads (JSON, YAML, INI with `cache: false`) go through the write queue, so one that finishes late cannot report the document as it was before a write. The file adapters write temporary files with a random name and an exclusive create (`FileSystemLike.writeNewFile`, provided by `nodeFileSystem`), skip a name that exists instead of writing through it, and only remove a file they created. The browser storage adapters read a key back after writing and report `conflict` if another tab's write landed after theirs; the docs now say plainly that the check is not atomic between tabs and point to `indexedDbAdapter`.
