Add the `/google-drive` entry point with `googleDriveAdapter()`, a best-effort adapter that keeps one plain-text file per key in a Google Drive folder, so small settings can be opened and edited by hand. It takes a Drive client (the one from `@googleapis/drive` fits) and a folder ID, stores the value as the file's content and the revision counter in the file's private properties, and remembers each key's file ID so repeat requests skip the search by name. Drive has no conditional write, so `ifRevision` is checked by reading then writing and is not atomic across processes; creating a key is checked by listing the folder afterwards, and the oldest file wins. `remove` deletes the file permanently. Errors explain a missing or unshared folder, a disabled Drive API, a missing scope, rate limits, and a full or missing storage quota (a service account has no Drive storage of its own, so it needs a shared drive: pass `sharedDrive: true`). `subscribe` hears other writers with `pollIntervalMs`. Tested against a stand-in for the Drive API; a test against a real Drive folder is included but skipped unless `TEST_GOOGLE_DRIVE_FOLDER_ID` is set.
